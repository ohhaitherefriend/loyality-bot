# ⚡ Быстрый старт - 3 команды

## На вашем Mac:

```bash
./docker-build-push.sh
```

Введите ваш Docker Hub username, подтвердите.

---

## На виртуалке в Яндекс Облаке:

### 1. Установите Docker (один раз):

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
sudo apt install -y docker-compose
```

Перелогиньтесь: `exit` и снова `ssh ubuntu@YOUR_IP`

### 2. Создайте конфиг:

```bash
mkdir loyalty-bot && cd loyalty-bot

cat > docker-compose.yml << 'EOF'
version: '3.8'
services:
  app:
    image: YOUR_USERNAME/loyalty-bot:latest
    container_name: loyalty-bot
    environment:
      TELEGRAM_BOT_TOKEN: your_token_here
      TELEGRAM_BOT_USERNAME: your_bot_username
      ADMIN_SECRET_CODE: your_secret
      SPRING_PROFILES_ACTIVE: prod
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
    restart: unless-stopped
EOF
```

**Отредактируйте** `YOUR_USERNAME` и переменные окружения!

```bash
nano docker-compose.yml
```

### 3. Запустите:

```bash
docker-compose up -d
docker-compose logs -f
```

---

## Обновление:

**На Mac:**
```bash
./docker-build-push.sh
```

**На сервере:**
```bash
cd loyalty-bot
docker-compose pull && docker-compose up -d
```

---

## 🆘 Проблемы?

```bash
# Логи
docker-compose logs -f

# Перезапуск
docker-compose restart

# Полная переустановка
docker-compose down
docker-compose pull
docker-compose up -d
```
