🎯 ПРОБЛЕМА:
Если вы на Mac M1/M2 и просто сделаете "docker build", образ не 
запустится на виртуалке в Яндекс Облаке (ошибка: exec format error)

✅ РЕШЕНИЕ (через Docker Hub - САМЫЙ ПРОСТОЙ):

./docker-build-push.sh

Скрипт автоматически:
- Соберет для AMD64 архитектуры
- Проверит корректность
- Опубликует в Docker Hub

На сервере просто: docker pull your-username/loyalty-bot:latest

═══════════════════════════════════════════════════════════

✅ Альтернатива (через Yandex Container Registry):

./docker-build-yandex.sh

🆘 ЧАСТЫЕ ОШИБКИ:

❌ docker build -t my-image .
   (Неправильно на Mac M1/M2!)

✅ ./docker-build-push.sh
   (Правильно! Самый простой способ через Docker Hub)

✅ docker build --platform linux/amd64 -t my-image .
   (Правильно, если вручную)

═══════════════════════════════════════════════════════════

💡 ПОЧЕМУ ЭТО ВАЖНО:

Mac M1/M2     → ARM64 архитектура
Яндекс Облако → AMD64 (x86_64) архитектура

Образы для разных архитектур несовместимы!

═══════════════════════════════════════════════════════════

🔍 ПРОВЕРКА:

После сборки проверьте архитектуру:
docker inspect your-image:latest --format='{{.Architecture}}'

Должно быть: amd64
