# Система Промо-Акций

## Обзор

Система промо-акций позволяет администраторам создавать временные акции со скидками для всех пользователей. Каждый пользователь может использовать промо-код только один раз.

## Возможности

### Для администраторов

1. **Создание промо-акции**
   - Нажмите кнопку "📢 Отправить скидку"
   - Введите процент скидки (1-100%)
   - Укажите срок действия в днях (1-365 дней)
   - Добавьте описание акции
   - Система автоматически создаст уникальные промо-коды для всех зарегистрированных пользователей

2. **Просмотр активных акций**
   - Нажмите кнопку "🎁 Активные акции"
   - Посмотрите список всех активных промо-акций с информацией о сроках и создателе

### Для пользователей

1. **Получение промо-кодов**
   - Существующие пользователи получают уведомление в боте при создании новой акции
   - Новые пользователи автоматически получают коды всех активных акций при регистрации

2. **Просмотр промо-кодов**
   - Нажмите кнопку "🎁 Мои скидки"
   - Увидите все доступные промо-коды с информацией о скидке и сроке действия

3. **Использование промо-кода**
   - Назовите промо-код администратору в магазине при покупке
   - Администратор вводит код через интерфейс бота
   - Скидка применяется автоматически
   - Код можно использовать только один раз

## Технические детали

### База данных

Создается новая таблица `promotions`:
- `id` - уникальный идентификатор
- `discount_percent` - процент скидки
- `description` - описание акции
- `expires_at` - дата окончания акции
- `created_by` - кто создал акцию (администратор)
- `is_active` - активна ли акция
- `created_at` - дата создания

### Как это работает

1. **Создание акции**:
   - Администратор заполняет диалог создания акции
   - Система создает запись в таблице `promotions`
   - Генерируются уникальные 8-значные промо-коды для всех пользователей
   - Коды сохраняются в таблице `discount_codes` с привязкой к пользователю
   - Отправляются уведомления всем пользователям

2. **Регистрация нового пользователя**:
   - При регистрации система проверяет активные акции
   - Для каждой активной акции генерируется промо-код
   - Пользователь получает уведомление о доступных акциях

3. **Использование промо-кода**:
   - Пользователь называет код администратору
   - Администратор вводит код через бот (любой код - и промо, и обычный)
   - Система проверяет статус кода и срок действия
   - Применяется скидка, код помечается как использованный

### Отличия от накопительной скидки

- **Накопительная скидка**: основана на сумме покупок за текущий месяц, обновляется автоматически
- **Промо-акция**: временная скидка с фиксированным процентом, действует определенный срок, используется один раз

## Примеры использования

### Создание недельной акции 10%

1. Администратор нажимает "📢 Отправить скидку"
2. Вводит: `10` (процент скидки)
3. Вводит: `7` (дней действия)
4. Вводит: `Осенняя распродажа`
5. Система создает акцию и отправляет коды всем пользователям

### Сценарий использования клиентом

1. Клиент получает уведомление: "🎉 Новая акция! Осенняя распродажа, скидка 10%, код: 12345678"
2. Клиент приходит в магазин и называет код
3. Администратор вводит код в бот
4. Скидка 10% применяется к покупке
5. Код больше не может быть использован

## Ограничения

- Максимальный процент скидки: 100%
- Максимальный срок действия: 365 дней
- Каждый промо-код можно использовать только один раз
- Промо-коды привязаны к конкретному пользователю

## Мониторинг

Администраторы могут:
- Просматривать список активных акций
- Видеть, кто создал каждую акцию
- Проверять сроки окончания акций
- Количество пользователей, получивших коды

## Будущие улучшения

- Промо-акции с определенным порогом покупки
