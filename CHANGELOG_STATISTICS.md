# 📊 Добавлен функционал статистики

## ✨ Что нового

### Для администраторов

Теперь кнопка **"📊 Статистика"** полностью работает и показывает:

#### 👥 Статистика пользователей
- **Всего пользователей** — общее количество зарегистрированных в боте
- **Зарегистрированных** — пользователи, завершившие регистрацию (указали телефон)
- **Администраторов** — количество админов в системе

#### 🎯 Распределение по уровням скидок
- **Без скидки (0%)** — клиенты с покупками менее 20,000 руб/мес
- **Базовый (5%)** — клиенты с покупками от 20,000 руб/мес
- **VIP (7%)** — клиенты с покупками от 25,000 руб/мес
- **Премиум (10%)** — клиенты с покупками от 30,000 руб/мес

#### 💰 Финансовая статистика
- **Общая сумма** — суммарные покупки всех клиентов за текущий месяц
- **Средняя на пользователя** — средняя сумма покупок на одного клиента

#### 🎁 Промо-акции
- **Активных акций** — количество работающих промо-акций

### SQL запросы для детального анализа

#### Статистика по уровням скидок
```sql
SELECT 
    CASE 
        WHEN monthly_spent >= 30000 THEN 'Премиум (10%)'
        WHEN monthly_spent >= 25000 THEN 'VIP (7%)'
        WHEN monthly_spent >= 20000 THEN 'Базовый (5%)'
        ELSE 'Без скидки (0%)'
    END as discount_level,
    COUNT(*) as user_count,
    SUM(monthly_spent) as total_spent,
    AVG(monthly_spent) as avg_spent
FROM users
WHERE state = 'REGISTERED' AND role = 'USER'
GROUP BY 
    CASE 
        WHEN monthly_spent >= 30000 THEN 'Премиум (10%)'
        WHEN monthly_spent >= 25000 THEN 'VIP (7%)'
        WHEN monthly_spent >= 20000 THEN 'Базовый (5%)'
        ELSE 'Без скидки (0%)'
    END
ORDER BY avg_spent DESC;
```

#### Общая статистика
```sql
SELECT 
    COUNT(*) as total_users,
    COUNT(CASE WHEN state = 'REGISTERED' THEN 1 END) as registered_users,
    COUNT(CASE WHEN role = 'ADMIN' THEN 1 END) as admins,
    SUM(CASE WHEN state = 'REGISTERED' THEN monthly_spent ELSE 0 END) as total_monthly_spent
FROM users;
```

## 🎯 Применение статистики

### Анализ эффективности программы лояльности

✅ **Отслеживание роста клиентской базы**  
Смотрите динамику регистраций новых пользователей

✅ **Понимание распределения клиентов**  
Видите, сколько клиентов на каждом уровне накопительной скидки

✅ **Планирование промо-акций**  
Если много клиентов без скидки и средняя покупка близка к порогу — создайте стимулирующую акцию

✅ **Оценка покупательской активности**  
Анализируйте среднюю сумму покупок на пользователя

### Пример анализа

```
Ситуация:
- Зарегистрированных: 125
- Без скидки: 98 чел. (78%)
- Средняя на пользователя: 19,606 руб.

Анализ:
- Большинство клиентов близки к порогу 20,000 руб. (5% скидка)
- Но не дотягивают совсем немного

Решение:
- Создать промо-акцию "Осенняя распродажа" 10% на неделю
- Это стимулирует клиентов сделать покупки
- После акции многие достигнут порога накопительной скидки 5%
```
