## 🎨 Настройка внешнего вида

### Через BotFather можно настроить:

1. **Аватар бота** - `/setuserpic`
2. **Описание** - `/setdescription`
3. **О боте** - `/setabouttext`
4. **Команды** - `/setcommands`

### Пример команд для BotFather:

```
start - Начать работу с ботом
help - Помощь
mypoints - Мой баланс баллов
history - История операций
discounts - Мои скидки
```

## 💬 Примеры сообщений для кастомизации

Все сообщения находятся в файле `LoyaltyBot.java` и легко настраиваются:

```java
// Приветствие
"👋 Добро пожаловать в программу лояльности!"

// Код покупки
"🛍 Код для покупки создан!\n\n📋 Ваш код: *" + code + "*"

// Начисление баллов
"✅ Вам начислено " + points + " баллов!"

// Уровень
emoji + " Уровень: " + user.getLoyaltyLevel().getDisplayName()
```

Вы можете изменить любой текст под свой бренд!
