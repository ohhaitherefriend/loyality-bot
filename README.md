# Zabotik Supplier Sync — Cursor Kit

Этот комплект предназначен для адаптации существующего `loyalty-bot` / «Заботик» в автоматический сервис синхронизации ассортимента поставщиков.

Основной сценарий:

```text
email -> Excel attachment -> layout detection -> parsing -> normalization
-> catalog matching -> price calculation -> snapshot reconciliation
-> automatic storefront update -> exception queue only when needed
```

Ручная загрузка — поздний резервный канал. Она не является MVP happy path.

## Как использовать

1. Распакуйте архив.
2. Перенесите содержимое папки `zabotik-cursor-kit` в корень актуального репозитория. Скрытую папку `.cursor` тоже нужно перенести.
3. Откройте репозиторий в Cursor.
4. Начните новый Agent-чат и вставьте содержимое `prompts/00-repo-audit.md`.
5. После аудита проверьте созданный Cursor файл `docs/SUPPLIER_IMPORT_AUDIT.md`.
6. Выполняйте промпты строго по порядку, каждый в отдельном чате.
7. Не запускайте следующий промпт, пока тесты предыдущего этапа не проходят и `docs/STATE.md` не обновлён.

## Что является источником истины

- Реальный код репозитория важнее предположений этого комплекта.
- `docs/ARCHITECTURE.md` описывает целевое состояние.
- `docs/DECISIONS.md` содержит обязательные продуктовые решения.
- `.cursor/rules/zabotik-supplier-sync.mdc` действует во всех Cursor-чатах.
- `docs/STATE.md` должен отражать только проверенное фактическое состояние.

## Ключевая бизнес-логика

- Каждый успешно обработанный `FULL` прайс — актуальный snapshot в пределах своего scope.
- Строка в snapshot создаёт или обновляет supplier offer.
- Отсутствующая строка деактивирует offer только после полного успешного импорта.
- Товар виден на сайте, пока существует хотя бы одно активное предложение поставщика.
- Запись товара физически не удаляется: сохраняются история заказов и learned matching.
- Цена сайта рассчитывается как `supplierPrice * (1 + commissionPercent / 100)`.
- При нескольких предложениях default — минимальная рассчитанная цена.
- Пустой, обрезанный или изменивший структуру файл не имеет права массово снимать товары.

## До начала разработки

Положите в закрытую test-fixtures директорию репозитория обезличенные примеры реальных Excel-файлов и, если возможно, исходные письма без персональных данных. Секреты почты и API-ключи в комплект не входят и не должны коммититься.
