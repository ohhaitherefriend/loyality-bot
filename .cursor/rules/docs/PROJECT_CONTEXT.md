# Контекст проекта

## Известная исходная база

Эти сведения получены из предыдущего состояния проекта и должны быть подтверждены Prompt 00:

- проект: `loyalty-bot` / «Заботик»;
- backend: Spring Boot 3.1.5, Java 21;
- основной package: `com.plstk.loyaltybot`;
- frontend: React/Vite в `admin-panel`;
- PostgreSQL и Flyway migrations;
- multi-tenant isolation по `shopId`;
- Apache POI использовался или планировался для XLSX;
- известный supplier workbook содержал листы «Косметика и уход» и «Парфюмерия», заголовки в строке 6, около 2481 позиции;
- существовали или проектировались commerce catalog, orders, Telegram Mini App и image pipeline;
- старые материалы противоречат друг другу по фактической готовности этих компонентов.

Актуальный репозиторий не был приложен при подготовке комплекта. Нельзя считать названия классов, migration numbers и endpoints подтверждёнными до аудита.

## Задача продукта

Поставщики регулярно отправляют на почту Excel-прайсы. Ассортимент и цены постоянно меняются. Система должна без ежедневного участия человека:

1. получить вложения;
2. определить поставщика и scope;
3. распознать layout;
4. привести разные варианты написания к единому каталогу;
5. рассчитать цену сайта с процентной надбавкой;
6. добавить новые товары и обновить существующие;
7. убрать с витрины отсутствующие позиции;
8. сохранить историю и вернуть товар автоматически, если он появится снова;
9. показать человеку только исключения и аварии.

## Пример matching

`Chanel`, `Шанель` и ошибочное `Channel` могут указывать на один бренд, но `Channel -> Chanel` нельзя делать глобальной строковой заменой. Она допустима только как contextual candidate signal в косметике/парфюмерии. Объём, концентрация, оттенок, комплектация и tester/retail являются критическими атрибутами.

## Внешние зависимости

- почтовый провайдер пока должен быть подтверждён;
- AI-провайдер на первом этапе — DeepSeek через OpenAI-compatible API;
- model/base URL задаются конфигурацией;
- production storage должен следовать реальным conventions проекта; целевой вариант — S3-compatible storage, локально допустим MinIO.
