# Обновление системы скидок

## Описание изменений

Система скидок была переработана с месячного сброса на 30-дневную персональную систему накопления.

### Старая система (до обновления):
- Скидка рассчитывалась на основе покупок за календарный месяц
- В начале каждого месяца счетчик сбрасывался
- Если пользователь накопил скидку в конце месяца, она сгорала с началом нового месяца

### Новая система (после обновления):
- Пользователь накапливает покупки независимо от календарных дат
- При достижении порога (20к/25к/30к руб) активируется скидка на 30 дней
- Счетчик накопления сбрасывается
- В течение 30 дней пользователь должен снова накопить порог для продления
- Если успел накопить - скидка продлевается еще на 30 дней
- Если не успел - скидка сгорает

## Изменения в коде

### 1. Entity User
**Файл:** `src/main/java/com/plstk/loyaltybot/entity/User.java`

Добавлены новые поля:
- `accumulatedAmount` - накопленная сумма для получения/продления скидки
- `discountEarnedAt` - дата активации скидки
- `discountLevel` - уровень скидки (5, 7 или 10)

Устаревшие поля (помечены @Deprecated):
- `monthlySpent` - оставлены для обратной совместимости
- `lastMonthReset` - будут удалены после миграции данных

Обновленные методы:
- `getDiscountPercent()` - возвращает скидку на основе `discountLevel` и срока действия
- `isDiscountValid()` - проверяет, не истекли ли 30 дней
- `getDiscountExpiresAt()` - возвращает дату истечения
- `getNextDiscountLevelInfo()` - показывает прогресс накопления или продления

### 2. Service UserService
**Файл:** `src/main/java/com/plstk/loyaltybot/service/UserService.java`

Переработаны методы:
- `addPurchase()` - новая логика с автоматической активацией/продлением скидки
- `processPurchase()` - упрощен, теперь просто возвращает текущую скидку и добавляет покупку
- `getUserStats()` - обновлен для работы с новыми полями

Удален метод:
- `extendDiscount()` - больше не нужен, продление происходит автоматически

### 3. Bot LoyaltyBot
**Файл:** `src/main/java/com/plstk/loyaltybot/bot/LoyaltyBot.java`

Обновлены методы отображения:
- `handleMyStatusButton()` - показывает срок действия скидки и прогресс накопления
- `handleAdminCodeInput()` - отображает накопленную сумму вместо месячных трат
- `handlePurchaseAmountInput()` - уведомляет об активации/продлении скидки
- Сообщения при регистрации обновлены

### Шаг 4: Восстановление скидок пользователям (АВТОМАТИЧЕСКИ)

**✨ Восстановление скидок происходит автоматически через Flyway миграцию!**

При первом запуске обновленного приложения Flyway автоматически выполнит миграцию `V1__restore_october_discounts.sql`, которая:
- Найдет пользователей с покупками в октябре >= 20,000 руб
- Восстановит их скидки с датой активации 1 ноября 2024
- Установит правильный уровень скидки (5%, 7% или 10%)

**Проверка выполнения:** Смотрите логи приложения:
```bash
docker-compose logs -f | grep -i flyway
# Вы увидите: "Flyway Migration V1: Восстановлено скидок: X"
```

**Подробности:** См. файл `FLYWAY_MIGRATION.md`

## Проверка работы

### Тестовый сценарий 1: Новый пользователь
1. Зарегистрируйте нового пользователя
2. Проверьте статус - должно быть "Накоплено: 0.00 руб"
3. Совершите покупку на 20,000 руб
4. Проверьте статус - должна активироваться скидка 5% на 30 дней

### Тестовый сценарий 2: Продление скидки
1. У пользователя есть активная скидка 5%
2. В течение 30 дней он накапливает еще 20,000 руб
3. При достижении порога скидка автоматически продлевается на 30 дней
4. Счетчик накопления сбрасывается на 0

### Тестовый сценарий 3: Истечение скидки
1. У пользователя есть активная скидка 5%
2. В течение 30 дней он не накопил нужную сумму
3. После 30 дней скидка перестает действовать
4. Накопленная сумма сохраняется
5. Пользователь продолжает накапливать для получения новой скидки

Добавить scheduled task для очистки истекших скидок:
```java
@Scheduled(cron = "0 0 3 * * *") // Каждый день в 3:00
public void cleanExpiredDiscounts() {
    List<User> users = userRepository.findAll();
    for (User user : users) {
        if (!user.isDiscountValid() && user.getDiscountLevel() != null) {
            user.setDiscountLevel(null);
            user.setDiscountEarnedAt(null);
            userRepository.save(user);
        }
    }
}
```
