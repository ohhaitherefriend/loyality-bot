# ⚡ Быстрый старт за 5 минут

## Шаг 1: Создайте бота в Telegram (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Назовите бота (например: "Моя программа лояльности")
4. Задайте username (например: `my_loyalty_bot`)
5. **Сохраните токен!** Он понадобится в следующем шаге

## Шаг 2: Настройте проект (1 минута)

```bash
# Создайте файл .env
cp env.example .env

# Откройте его и вставьте токен вашего бота
nano .env
```

В файле `.env` укажите:
```
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz  # Ваш токен от BotFather
TELEGRAM_BOT_USERNAME=my_loyalty_bot                     # Username вашего бота
```

## Шаг 3: Запустите (2 минуты)

```bash
# Запустите
./run.sh
```

Или вручную:
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен"
export TELEGRAM_BOT_USERNAME="ваш_username"
mvn spring-boot:run
```

## Шаг 4: Протестируйте ✅

1. Найдите бота в Telegram по username
2. Отправьте `/start`
3. Зарегистрируйтесь по номеру телефона
4. Готово! 🎉

## 🔧 Создание администратора

### ✨ Способ 1: Через команду /makeadmin (быстро!)

1. В файле `.env` добавьте:
```
ADMIN_SECRET_CODE=мой_секретный_код_123
```

2. Перезапустите бота

3. Зарегистрируйтесь в боте (`/start`)

4. Отправьте команду:
```
/makeadmin мой_секретный_код_123
```

5. Готово! Отправьте `/start` - увидите админское меню!

**Подробнее:** см. файл `ADMIN_QUICKSTART.md`

### Способ 2: Через SQL (классический)

1. Откройте http://localhost:8080/h2-console
2. Параметры подключения:
   - URL: `jdbc:h2:file:./data/loyaltydb`
   - User: `sa`
   - Password: (пусто)
3. Выполните SQL (замените номер на свой):
```sql
UPDATE USERS SET ROLE = 'ADMIN' WHERE PHONE_NUMBER = '+79001234567';
```

4. Перезапустите бота командой `/start` - увидите админское меню!

## ❓ Частые вопросы

**Q: Бот не отвечает**
- Убедитесь, что приложение запущено (смотрите логи в консоли)
- Проверьте правильность токена

**Q: Как изменить количество баллов за покупку?**
- Откройте `src/main/java/com/plstk/loyaltybot/bot/LoyaltyBot.java`
- Найдите строку `int pointsToAdd = 10;` (примерно строка 275)
- Измените на нужное значение

**Q: Как изменить время действия кода покупки?**
- В файле `application.yml` измените параметр:
```yaml
loyalty:
  purchase-code:
    expiration-minutes: 10  # Измените на нужное количество минут
```

**Q: Как добавить PostgreSQL вместо H2?**
- См. раздел "Запуск с PostgreSQL" в файле `SETUP.md`
