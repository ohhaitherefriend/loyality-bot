# 🎭 Как работает разделение на админов и пользователей?

## Ответ на ваш вопрос

> "Хм, ты сделал функционал для админов и пользователей в одном приложении? А как определять кто есть кто?"

**Да!** Это один бот для всех, но с разными интерфейсами.

## 🔐 Механизм работы

### 1. Роль хранится в базе данных

В таблице `users` есть поле `role`:
- `USER` - обычный клиент (по умолчанию)  
- `ADMIN` - администратор

### 2. Все регистрируются как USER

При `/start` каждый получает роль `USER` автоматически.

### 3. Бот проверяет роль при каждом действии

```java
if (user.getRole() == User.UserRole.ADMIN) {
    // Показываем админское меню
} else {
    // Показываем клиентское меню
}
```

## 🚀 Как назначить администратора

### Способ 1: Команда /makeadmin (новый!)

```bash
# В .env добавьте:
ADMIN_SECRET_CODE=мой_секретный_код

# Перезапустите бота
./run.sh

# В Telegram:
/start
/makeadmin мой_секретный_код
```

✅ Готово! См. `ADMIN_QUICKSTART.md` для деталей

### Способ 2: SQL (классический)

```sql
UPDATE users SET role = 'ADMIN' WHERE phone_number = '+79001234567';
```

## 🛡️ Безопасность

Каждая админская функция защищена:

```java
if (user.getRole() != User.UserRole.ADMIN) {
    sendMessage(chatId, "❌ Доступ запрещен");
    return;
}
```
