# Environment variables draft

Это концептуальный список. Prompt 00/01 должен адаптировать имена к `@ConfigurationProperties` и conventions реального проекта.

```dotenv
SUPPLIER_IMPORT_ENABLED=true
SUPPLIER_IMPORT_POLL_INTERVAL=PT5M
SUPPLIER_IMPORT_MAX_FILE_BYTES=52428800
SUPPLIER_IMPORT_MAX_ROWS=100000
SUPPLIER_IMPORT_JOB_CONCURRENCY=2

MAILBOX_ENABLED=true
MAILBOX_HOST=
MAILBOX_PORT=993
MAILBOX_USERNAME=
MAILBOX_SECRET=
MAILBOX_AUTH_MODE=OAUTH2
MAILBOX_ENCRYPTION_MASTER_KEY=

AI_MATCHING_ENABLED=true
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=
DEEPSEEK_TIMEOUT=PT30S
DEEPSEEK_MAX_CONCURRENCY=4

IMPORT_STORAGE_TYPE=s3
IMPORT_STORAGE_BUCKET=
IMPORT_STORAGE_ENDPOINT=
IMPORT_STORAGE_ACCESS_KEY=
IMPORT_STORAGE_SECRET_KEY=
```

Ни один секретный value нельзя коммитить. Sample env содержит только пустые placeholders.
